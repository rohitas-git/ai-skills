# Imported planning-and-task-breakdown provenance

This file records the source family for useful ideas folded into `/1-to-tickets`: explicit acceptance
criteria, dependency ordering, independently verifiable slices, and visible checkpoints.

It is **provenance only** and is not operative for `/1-to-tickets`. The former imported workflow also
mandated plan files, fixed task directories, human review loops, file-count/time heuristics, checkpoint
cadence, and implementation handoffs. Those defaults conflict with the live skill's approved-spec,
one-ticket-set, destination-aware boundary and must not be invoked from this file.

The live authority and process are defined only by `../SKILL.md` and
`sizing-checkpoints-parallel.md`.
