# Source adaptation

Source: [nicobailon/visual-explainer](https://github.com/nicobailon/visual-explainer/tree/9d5f880b7e8e0a9a80c890b8e1bb6918b68481ad).
Version: 0.15.0. Commit: `9d5f880b7e8e0a9a80c890b8e1bb6918b68481ad`.
License: MIT, Nico Bailon, 2025; a copy is included in this package.

Retained: figure-led explanations, answer-first composition, one claim per caption,
mechanism drawings, matched before/after views, visual registers, small multiples,
source-backed comparisons and context recaps, optional stepper/replay/live illustrations,
plain English, accessibility, and source visibility.

Adapted: one local offline HTML artifact, native HTML/CSS/SVG, explicit invocation,
bounded evidence inspection, source escaping, retained uncertainty, optional browser inspection,
and clear boundaries with the catalog's existing diagram/recap/plan/slides owners.

Not imported: upstream kit, renderer, executable model walker, Pi extension, MCP server,
HTML templates tied to the kit, CDN assets, exporters, video/narration integrations,
feedback runtime, installers, global output/configuration, automatic opening or large-table conversion.
These are separate capabilities with dependencies and effects, not hidden requirements of this skill.

No upstream code was executed or adopted as an executable helper. Selected upstream Markdown
and metadata are retained as non-discoverable source evidence with hashes.
The rest of the plugin has not received a complete code/security audit.

Assessment, integration gate, source manifest, capability mapping, and validation:
[ingest report](../../../guidelines/catalog/ingest-visual-explainer-2026-11-12.md).
