# Historical example note: Clean-books narrative

An earlier version of Story Teacher used a long paraphrased summary of *Clean Code* and
*Clean Architecture* as an example input for a cyberpunk story concept. That summary mixed
source claims, later interpretation, fixed numeric rules, and disputed engineering advice
without a precise edition/page ledger.

It is retained only as provenance for the skill's former design. It is **not an operative
source, correctness authority, reusable summary, or instruction set**. Do not teach from,
quote, or apply its claims without checking an authorized source and the user's current
repository context. The useful structural lesson is only that a narrative transformation
must distinguish source-backed ideas, caveats, simplifications, and fictional inventions.
