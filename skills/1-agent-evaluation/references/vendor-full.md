# Upstream Agent Evaluation snapshot

Historical source snapshot, not operative instructions. The live skill and its two active
references control candidate identity, authority, privacy, experimental design, and reporting.

Source: `seb1n/awesome-ai-agent-skills`, upstream skill `agent-evaluation`, commit
`75865a5d037a4cdaa7f409a4ec14ab9b0292920b` (MIT).

Ideas retained after adaptation:

- define the decision and unit under test before cases or metrics;
- connect representative cases and high-impact risks to observable criteria;
- match graders to claims and inspect failures before aggregates;
- freeze comparable candidate/protocol versions and preserve holdout integrity;
- report uncertainty and let an accountable owner make release decisions.

Not adopted as defaults: a mandatory five-artifact package, fixed task/risk/language slices,
unqualified model grading, production execution, external data transfer, three repetitions,
automatic regression-fixture writes, or automatic ship/hold/limited-rollout decisions.
