# Historical monolithic Hatch Pet guide

The former 925-line create/research/generate/validate/install/cleanup workflow was retired during atomization.
It mixed independent effects, mandatory delegation, guessed host tools, global installation, destructive cleanup,
and fixed timing/retry rituals. Git history preserves the source for provenance; it is not execution guidance.

Use the focused live routes instead:

- `/2-hatch-pet-build`
- `/2-hatch-pet-repair`
- `/2-hatch-pet-validate`
- `/2-hatch-pet-install`

The stable v2 data contract remains in [codex-pet-contract.md](./codex-pet-contract.md); animation semantics and
QA criteria remain in [animation-rows.md](./animation-rows.md) and [qa-rubric.md](./qa-rubric.md).
