# V2 candidate build pipeline

This reference defines dependencies and outputs; it grants no image, network, write, overwrite, cleanup,
delegation, or installation authority.

1. Resolve the loaded `1-hatch-pet` package as `PET_SKILL_ROOT`. Select an existing compatible Python runtime with
   Pillow; never install or upgrade dependencies silently. Run bundled helpers only from this exact package.
2. Use a new empty run-owned destination. `prepare_pet_run.py` may create prompts, copied references, layout guides,
   and a job manifest there. Do not pass `--force`; a collision or non-empty destination is a stop condition.
3. Generate the canonical base, each required standard row, four cardinal anchors, then coherent look rows through
   `/1-imagine`, one pinned visual job/result at a time. Attach only the manifest-listed authorized references.
   Never auto-research a brand or use generated pixels as proof of exact geometry.
4. After each selected result is copied into its declared run-owned path, record its source hash and run the fitting
   deterministic extraction/inspection helper. Generate `running-right` before deciding whether a mirror preserves
   identity/handedness; otherwise generate `running-left`. A look-row repair replaces the coherent row, not one cell.
5. Assemble rows 0–8, inspect contact sheets and motion previews, approve cardinal semantics, register row 9, then
   generate/register row 10. Apply one final despill pass only after the 8×11 atlas exists; then validate v2 geometry,
   transparency, cells, direction order, motion continuity, identity, and state semantics.
6. Produce one candidate directory containing `pet.json`, `spritesheet.webp`, validation report, contact/direction
   sheets, and provenance/QA summary. Preserve intermediates by default. Installation and cleanup are separate.

Visual judgment may be serial. Use independent or parallel reviewers only when explicitly requested or required by
the caller's acceptance contract; delegation never carries write, cleanup, or installation authority.
