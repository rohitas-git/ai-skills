# Living-document baseline

Follow an existing repository template first. When none exists, adapt this minimal shape:

```markdown
# Topic

Purpose, audience, and supported scope.

## Current behavior

Source-backed behavior, entry points, and constraints.

## Operations or use

Verified commands/flows when applicable.

## Limits and unknowns

Known gaps, unsupported cases, and evidence limits.

## Sources and owners

- `path`, symbol/section/lines — claim supported
```

Add a diagram only when relationships are materially clearer visually. Dates, frontmatter, naming,
status, ownership, and navigation follow local conventions. Do not require one Mermaid diagram,
“At a glance” block, or canonical-owner field on every page.
