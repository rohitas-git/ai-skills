# Lateral move guide

Optional one-move menu for `/1-thinking-lateral`; it adds no evidence, constraint waiver, tool
authority, or implementation step.

- **Provocation:** suspend one assumption nonliterally, extract a practical mechanism, then derive candidates.
- **Random entry:** map one unrelated property to a mechanism before applying it; reject decorative analogy.
- **Rule challenge:** identify one implicit rule, its evidence and owner, then imagine the problem with
  the rule changed while preserving load-bearing constraints.
- **Concept fan:** move from the stated method to its purpose, then derive alternative methods.

Stop when candidates expose a genuinely different mechanism or when no move survives constraints.
Do not chain moves for volume, bypass safety/law/ethics, or present generated novelty as fact.
