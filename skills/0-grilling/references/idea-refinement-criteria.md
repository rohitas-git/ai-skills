# Retired refinement-criteria provenance

This checklist is non-operative for `/0-grilling`; `/1-brainstorm` owns option comparison.

Useful retained dimensions, applied only when relevant and backed by evidence, are user value,
compatibility, feasibility, security/privacy, accessibility, operability, reversibility, dependency
risk, validation cost, and differentiation. The candidate owner supplies priorities and mandatory
constraints.

Do not use “painkiller versus vitamin,” fixed matrices, numeric weights, frequency claims, market
rankings, or MVP slogans as universal truth. Do not invent users, switching behavior, cost, adoption,
competitors, or technical feasibility. If evidence cannot distinguish options, return the missing
observation or decision instead of forcing a winner.
