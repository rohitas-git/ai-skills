# Retired ideation-example provenance

This reference is non-operative for `/0-grilling`.

The former long examples are not live instructions or evidence. They mixed invented market numbers,
competitor claims, user behavior, architecture assertions, and bundled questions into polished stories.
That pattern can create unjustified confidence.

Safe illustrative shape:

```text
Observed/supplied: <facts with source and cutoff>
Generated option: <clearly labeled hypothesis>
Trade-off: <mechanism, benefit, cost, uncertainty>
Discriminating evidence: <what would change the choice>
Non-goal: <explicit exclusion>
```

Examples must use fictional or explicitly supplied facts, avoid implying code inspection that did not
occur, and never authorize research, user contact, experiments, document writes, or implementation.
Live design-alternative work routes to `/1-brainstorm`.
