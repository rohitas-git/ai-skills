# Beginner audience guide

Assume no topic-specific prerequisite, not low intelligence.

- Start with the core idea and define terms before relying on them.
- Use a concrete example when it resolves an abstraction.
- Sequence prerequisites before consequences; avoid unexplained acronym stacks.
- Name one important limitation only when omission would mislead.
- Do not force encouragement, repetition, analogy, diagrams, or a quiz.

Preserve technical truth and uncertainty; simplicity changes wording, not facts.
