# Specialist audience guide

Use when the user states relevant professional or working knowledge.

- Start at the evidenced prerequisite level; do not reteach basics unnecessarily.
- Emphasize mechanisms, constraints, failure modes, and decision trade-offs relevant
  to the user's actual practice.
- Name tools or workflows only when current evidence supports them.
- Separate universal principles from organization-, jurisdiction-, or stack-specific
  practice.
- Keep safety, compatibility, and uncertainty visible.

Do not infer specialist status from jargon alone or add implementation instructions
when the user asked only for understanding.
