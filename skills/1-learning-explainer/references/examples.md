# Style examples — not factual sources

Examples illustrate audience adaptation only. Never copy their topic claims as
evidence; verify the actual subject independently when needed.

For one stable mechanism:

- **Beginner:** core idea → define one necessary term → concrete consequence.
- **General audience:** core idea → mechanism → why it matters to the stated goal.
- **Specialist:** mechanism → operating constraint → trade-off/failure mode.
- **Academic:** precise framing → evidentiary method → limitation or competing view.
- **Frontier:** established baseline → dated current evidence → disagreement/unknown.

The same causal conditions and uncertainties must survive every version. Adapt wording
and assumed prerequisites, not truth. Do not generate all levels unless explicitly
requested.
