# Child audience guide

Use only when the user explicitly identifies a child audience or asks for child-level
language. Do not infer age from “ELI5.”

- Use concrete familiar objects and short causal steps.
- Define necessary terms rather than banning accurate vocabulary.
- Avoid frightening, patronizing, or falsely magical claims.
- Preserve exceptions and safety conditions in age-appropriate language.
- An analogy is optional; if used, say where it stops matching reality.

Return one coherent explanation, not mandatory games, praise, or follow-up questions.
