# Audience and mode routing

Audience cues select vocabulary and prerequisites:

| Cue | Starting assumption |
|---|---|
| child / ELI5 | concrete language; define every necessary technical term |
| beginner / from scratch | no topic prerequisite; ordinary adult language unless age is stated |
| layperson / general audience | general knowledge, no domain specialization |
| specialist / practitioner | working domain knowledge; emphasize operational trade-offs |
| academic / graduate | formal concepts and methodological precision |
| frontier / state of the art | expert prerequisites plus current-source verification |

Level guides: [child](./level-child.md), [beginner](./level-beginner.md),
[layperson](./level-layperson.md), [academic](./level-academic.md),
[specialist](./level-specialist.md), and [frontier](./level-frontier.md).

Mode cues route to separate skills: model/visual → `1-mental-model-builder`; go deeper
→ `1-progressive-deep-dive`; quiz/practice → `1-tutor`; selected material →
`1-explain-with-example`; concise/detailed presentation →
`1-response-effort-calibrator`; current web evidence → `1-research`.

Do not silently combine modes. “Frontier” does not itself authorize browsing, and
“visual” does not authorize creating an image or file.
