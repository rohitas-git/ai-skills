# Mental-model selection

Choose the form that exposes the relation the learner needs:

| Relation | Candidate form |
|---|---|
| transformation | input → process → output |
| sequence/state | flow or state transition |
| feedback over time | causal loop |
| alternatives | comparison dimensions |
| containment/dependency | hierarchy or graph |
| unfamiliar mechanism | analogy to a known mechanism |

A useful model must map elements explicitly, support at least one prediction or
explanation, and name where it breaks. Familiarity alone does not make an analogy
accurate. Produce text/specification only; a rendered artifact requires the diagram or
image workflow and explicit user intent.
