# Ingest and update workflow

Load only for an authorized ingest or wiki update.

## Input ledger

Before editing, list:

- exact sources and locators;
- source status: current, historical, proposed, superseded, or uncertain;
- existing wiki pages that overlap;
- requested output scope and explicit exclusions;
- unresolved contradictions or material page-structure choices.

A user's clear request to ingest named sources authorizes the scoped wiki edits. Ask before writing
only when source authority, destination, destructive restructuring, or page decomposition remains a
material choice. Do not require a ceremonial second approval for an already approved plan.

## Synthesis loop

1. Read the complete relevant source when feasible. For large/binary material, record coverage and
   use the appropriate document/image tool; never imply full coverage from an excerpt.
2. Extract decision-relevant facts, concepts, relationships, constraints, and open questions. Do not
   target an arbitrary number of takeaways or pages.
3. Search the existing index and candidate pages. Update the same concept rather than cloning it;
   preserve distinct concepts when merging would erase a real boundary.
4. Draft the smallest useful source-summary or concept-page set. Label proposals, historical states,
   contradictions, user-confirmed facts, and agent synthesis explicitly.
5. Update only the established index and append-only log mechanisms that apply to this wiki.
6. Inspect the final diff for source mutations, unrelated formatting, duplicate content, broken links,
   missing citations, and accidental scope expansion.

## Existing and changing sources

- A newer source does not silently erase an older claim. Record supersession only when the evidence
  or user decision says so.
- When a raw file changes, update only affected pages unless the change invalidates the entire source.
- If sources conflict, retain both positions with locators and resolution status.
- Do not delete historical pages solely because they are stale; mark status and link the successor.
- Never create pages merely to hit a page-count target. Split when the result has distinct readers,
  ownership, or change cadence—not at a universal word count.

## Output

Return created/updated paths, sources and coverage, important connections, conflicts, validation
results, and remaining user decisions. Do not offer unrelated wiki expansion as though it were part
of the completed request.
