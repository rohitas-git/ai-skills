# Historical design provenance

The original Vault workflow was inspired by a Karpathy LLM Wiki gist and project-wiki
compiler metaphors. Those sources motivated source grounding, explicit ingest/query/lint
ownership, conflict visibility, and indexable notes.

This reference is historical context, not an operative workflow or current-source claim.
It does not authorize a dual raw/wiki layout, fixed filenames, page splitting, mandatory
confirmation, automatic logging/archive, source deletion, URL fetching, or treating the
agent's synthesis as compiled truth. The current Vault schema, leaf contract, selected
source evidence, and user authority control every operation.
