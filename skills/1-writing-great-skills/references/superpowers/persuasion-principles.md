# Persuasion Source — Safety Adaptation

Source: a vendored discussion of persuasion principles for agent instructions.

Status: provenance note only; persuasion is not a catalog objective.

Use clarity, observable triggers, and checkable completion criteria. Strong language is appropriate only for genuine safety, authority, privacy, correctness, or irreversible-effect boundaries.

Do not use authority, scarcity, social proof, commitment devices, urgency, guilt, affinity, or false consensus to make an agent comply with an instruction that would not otherwise be justified. Never use prompt technique to bypass user choice, platform policy, repository rules, review judgment, or a missing permission.

The test is not “did compliance increase?” It is “does this wording help the agent follow a legitimate, transparent user-serving contract without distorting judgment?” If not, remove it.
