# Superpowers Writing-Skills Source Adaptation

Source: the vendored Superpowers writing-skills guide previously preserved in this package.

Status: provenance note only; it is not an operative workflow.

## Retained ideas

- Test uncertain behavior against realistic tasks.
- Compare against a baseline when the comparison answers a real question.
- Read traces and revise generalized failure causes, not one output.
- Keep the main skill concise and place conditional depth behind clear pointers.
- Match instruction form to the observed failure.

## House differences

The upstream “skill creation is TDD” iron law is not adopted. A user may request a draft, a small correction, or a reference-only update without a formal failing baseline. Evaluation depth is proportional to risk and uncertainty.

No subagent, browser, viewer, package install, deployment, commit, push, or publication follows automatically. Existing host policy and explicit user authority govern those effects.

Pressure scenarios must not deceive an agent about real authority or encourage destruction. Positive output contracts are preferred; prohibitions are reserved for genuine safety/correctness boundaries.

Use `/0-skill-creator` for the current operational contract and `/1-writing-great-skills` for current craft rules.
