# Historical query design context

This note records ideas adapted from the Karpathy LLM Wiki gist and community implementations.
It is historical design context, not an operative checklist, source of vault facts, or authority
to read/write files.

Useful ideas retained conditionally:

- synthesized notes can be more efficient evidence than repeatedly processing raw sources;
- a human-readable index can narrow retrieval before content search;
- answers should distinguish note evidence from synthesis and gaps;
- a useful answer may later become a separately authorized knowledge artifact.

These ideas do not require a fixed index-first ritual, embeddings, a page-count threshold,
automatic query logging, automatic filing, or treating compiled notes as current truth. The
active vault schema, the user's scope, and the main skill's evidence/authority rules control.
