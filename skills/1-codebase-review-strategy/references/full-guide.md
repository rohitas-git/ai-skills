# Upstream codebase-review workflow adaptation

This file is a provenance note only. The imported guide supplied useful ideas about repository measurement,
risk-based coverage, evidence, and specialist handoffs, but also mandated questionnaires, fixed LOC tiers, sample
quotas, broad scans, tool installation, and review execution.

The live skill uses repository risk and decision need—not arbitrary size thresholds—to produce a read-only coverage
plan. It never installs scanners, executes the review, or widens beyond the pinned scope. `../SKILL.md` is authoritative.
