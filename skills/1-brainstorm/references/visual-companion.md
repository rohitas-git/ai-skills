# Legacy visual-companion provenance

This document and `references/scripts/` preserve an imported Superpowers visual-brainstorming helper.
They are **not live instructions for `/1-brainstorm`** and must not be loaded or executed automatically.

The helper can create project-local files, bind a local HTTP/WebSocket server, expose a keyed URL,
launch a browser, persist session state, and stop processes. Those effects exceed Brainstorm's
analysis-only authority and require a separately selected visual/tool workflow plus explicit approval.

For a visual comparison, route deliberately through the smallest current visual skill, normally
`/1-visual-plan`, `/1-diagram-maker`, or the applicable UI/UX skill. Preserve the caller's exact
repository/worktree, data-sensitivity, network-bind, browser-launch, file-write, and cleanup authority.

Upstream provenance: `obra/superpowers` brainstorming visual companion. The retained scripts are
historical source material only; presence in this directory is not permission to run them.
