# One-icon guidance

Pin the icon's meaning, context, size, stroke/fill convention, color behavior, and target format. Reuse the product's
existing icon system when the brief requires consistency. Keep paths simple and legible at the actual size; use a
correct viewBox, accessible name/label policy, and `currentColor` when appropriate. Validate SVG as untrusted XML and
exclude scripts, event handlers, raster embeds, and remote references. One icon request does not authorize a set.
