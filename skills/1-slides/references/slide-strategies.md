# Narrative strategy guidance

Select a narrative from the audience's decision need, not a named formula by default. Useful shapes include:

- context → evidence → implication → recommendation → decision;
- problem → constraints → options → trade-offs → next step;
- claim → proof → counter-risk → mitigation → ask;
- current state → desired state → credible bridge.

Every slide should advance one part of the argument. Label missing evidence and remove unsupported persuasion. Investor,
sales, board, teaching, and status decks have different disclosure duties; the supplied purpose and repository policy win.
