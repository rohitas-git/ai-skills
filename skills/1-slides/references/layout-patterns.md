# HTML slide layout patterns

Choose the smallest layout that expresses the content relationship: centered title, split comparison, feature grid,
metric set, timeline, evidence table, screenshot, or closing decision/CTA. Preserve reading order in the DOM. Use
responsive CSS that becomes one column when necessary; avoid fixed-height clipping, unreadably small type, and visual
ordering that differs from keyboard/screen-reader order. A pattern is a starting point, not authority to invent content.
