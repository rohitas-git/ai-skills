# Upstream doubt-driven workflow adaptation

This file is a provenance note only. The original CLAIM → EXTRACT → DOUBT → RECONCILE frame is retained. Mandatory
fresh agents, cross-model CLIs, repeated cycles, and automatic follow-on actions are not.

The live skill performs one read-only pass over one immutable claim, uses only authorized evidence, returns
`keep`/`revise`/`reject`/`unknown`, and leaves any further review or action to the caller. `../SKILL.md` is authoritative.
