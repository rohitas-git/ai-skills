# Hatch Pet atomization and wiring audit

Reviewed `1-hatch-pet`, its complete former 925-line guide, all four operative reference files, its 17 helper
interfaces/write surfaces, six helper test modules, current image-generation boundary, and Office/sub-hub routes.

## Result

The former leaf combined brand research, image generation, preparation, deterministic raster transformation,
visual review, repair, packaging, global installation, cleanup, and mandatory subagent orchestration. It is now a
pure sub-hub with four depth-correct children: build one new validated local candidate, repair one verified defect
in a copied candidate, read-only validate one immutable package, or explicitly install one already validated package.
F-PET1 exists only for material operation ambiguity; no operation is chained or inferred from “hatch.”

Every route pins caller, immutable candidate/request and hashes, v2 contract, source/destination, rights/privacy,
overwrite/cleanup rules, authority, and optional exact repository/worktree provenance. Worktrees are not claimed to
isolate the image provider, generated stores, Codex home, installed pets, accounts, running apps, or shared files.
Build uses a fresh run-owned directory, calls `/1-imagine` once per visual job, preserves a canonical identity, and
stops at a validated candidate. It performs no brand research, hidden dependency install, global installation,
publication, cleanup, or mandatory delegation.

Repair protects requested identity/design and changes one deterministic defect or one packaging-eligible visual row,
never an installed pet in place. Validation writes no sidecar report and distinguishes geometry/transparency evidence
from identity/motion/direction coverage. Install requires an explicit request plus hash-bound validation, exact global
destination and collision policy; it stages the manifest/spritesheet pair and never activates, syncs, or cleans up.
The helper safety contract adds containment, collision, revision, untrusted-input, and source-preservation gates.

The monolithic guide is now a short historical note. Stable contract/row/QA references remain lean. An accidental
catalog-wide replacement of the pet animation state `review` with `0-review` was corrected. The despill helper now
uses Pillow's current flattened-pixel API with an older-runtime fallback, eliminating current deprecation warnings.
