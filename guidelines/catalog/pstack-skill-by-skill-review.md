# pstack skill-by-skill review

Reviewed every `SKILL.md` in the pinned [pstack 0.15.43 tree](https://github.com/cursor/plugins/tree/e1cc03121a0e71129a4fb730d7c5528a0a3e43c8/pstack), including the three Benny automation skill bodies. This pass covers 24 principle skills, 34 functional skills and three automation skills. The earlier [method review](./pstack-methods-review-2026-11-18.md) includes the 22 playbooks and explains their adoption.

For each skill, the table links the pinned source and the live catalog guidance checked in this pass. **Applied** means a new refinement landed in an existing owner. **Kept** means the existing behavior covers the lesson or the portable portion of it. The acceptance examples describe what an agent following the guidance should do. They are review scenarios and do not report live agent trials. This pass applied 14 skill-level refinements and retained the existing treatment for 47 skills.
