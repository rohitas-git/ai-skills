# UI/UX Pro Max wiring audit

Reviewed `1-ui-ux-pro-max`, every live Markdown reference, the bundled search/data implementation, its regression
tests, parent UI/UX routes, and adjacent Brand, Design System, Styling, Frontend UI, Research, and Audit boundaries.

## Result

The skill now owns one read-only design-direction packet for one immutable product surface. It pins the actual caller,
question, audience, constraints, evidence cutoff, incumbent brand/design rules, and—when repository context matters—
the exact repository/worktree/branch/`HEAD`, dirty ownership, relevant files, stack, and deployed-versus-working-tree
identity. It creates no worktree and does not claim that Git isolates browsers, servers, ports, fonts, design tools,
analytics, cloud assets, accounts, participants, or published UI.

The bundled corpus and its snippets are explicitly untrusted, snapshot-bounded guidance rather than proof of current
standards, user behavior, business outcomes, accessibility conformance, or correctness. Queries use the smallest
explicit domain or detected stack; zero, weak, and contradictory matches remain visible. Repository and product
evidence outrank generic corpus suggestions, and project `docs/brand.md` remains authoritative.

The former mandatory design-system-first, persist, implement, and pre-delivery pipeline was removed. `--design-system`
is permitted only as a read-only cross-dimension recommendation. `--persist`, `--force`, implicit destinations,
browsing, installs, assets, code/file edits, browser/server runs, testing, publication, and implementation are outside
this skill. Durable design-system artifacts and every downstream effect require a separately authorized specialist
handoff carrying the same candidate and authority contract. The obsolete Claude-plugin path was replaced by the live
skill-relative script path, and the 210-line mega-guide became lean compatibility notes.
