## Shared contract

Each skill now pins its actual caller and immutable candidate, distinguishes repository worktree isolation from shared
browser/account/service/provider state, treats imported and external content as untrusted, separates read-only and
mutating effects, rechecks revision/collision before writes, verifies only supported claims, and returns to the caller
without using a `next` relationship as execution authority.

Imported mega-guides were reduced to bounded guidance or provenance notes. The live network-generating design helpers
that loaded ambient secrets and called stale Gemini models were removed; their original versions remain in the archived
vendor source. Local CSV search helpers remain non-authoritative, read-only reference aids.

## Wiring decisions

- UI/UX directly distinguishes one identity/social asset, one promotion, one HTML deck, and one read-only customer audit.
- Review exposes Doubt Driven Development and treats codebase strategy as an on-ramp that returns a plan; the old F-R4
  “continue strategy as reviewer” fork was removed.
- Git text normalization returns after diagnose/fix; a commit is separately requested.
- Ship research returns one answer; persistence and implementation are separate effects.

## Verification standard

Regression tests assert atomicity, candidate/worktree/effect identity, caller returns, retired unsafe procedures,
parent/flow parity, and valid live paths. Full routing, catalog lint, route-index regeneration, JSON parsing, inventory
reconciliation, and `git diff --check` are run only after the tracker and projections are current.
