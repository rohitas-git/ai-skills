# Imagine wiring audit

Reviewed `1-imagine`, the complete 315-line installed `imagegen` skill, the current host tool contract, and
adjacent Office, deterministic-diagram, UI/UX, and animated-pet routes.

## Result

Imagine is now a thin catalog bridge for exactly one raster-image generation or edit operation returning one
selected result. It delegates execution details to the installed host image-generation skill and current tool
schema rather than naming a vendor or duplicating volatile model, parameter, path, or fallback guidance. Exact
labels, data, and topology route to deterministic visuals; UI/design decisions and animated-pet packages retain
their specialist owners.

The operation pins caller, request version, generate/edit intent, output use and destination, composition and size
intent, text, invariants, reference roles, privacy/rights/consent, overwrite/publication rules, authority, and exact
optional repository/worktree identity. Worktrees are not claimed to isolate provider accounts, remote processing,
generated-image stores, URLs, or destinations. Prompts, pixels, metadata, filenames, OCR, and links are sensitive
untrusted input; local or third-party references are not implicit permission to transmit, search, fetch, or publish.

Current reference semantics are explicit: new generation omits both reference mechanisms; local edit targets are
inspected first; all-local targets use paths; conversation-only targets use the smallest sufficient recent-image
window; the two mechanisms are never combined; missing targets require reattachment. Prompt normalization preserves
the user's requirements without inventing facts or brands. Verification inspects observable visual properties while
refusing to claim that model output proves exact text, data, identity, trademarks, historical facts, or structure.

The former Grok-specific two-tool contract, unsupported `image_edit`/aspect-ratio parameters, automatic web search,
named-person absolutes, speculative video tools, FFmpeg assembly, and hidden multi-variant workflow were removed.
Video, publication, consuming-code edits, uploads, further variants, and materially new transformations remain
separate authorized operations.
